# Aquanova project assets

The editor reads reusable models from the external BabylonAssets kit library. Each kit directory contains its own license information. The published `scene.glb` embeds the Aquanova assembly of the CC0 Quaternius Modular SciFi MegaKit.

`env/bank_vault_2k.hdr` is the **bank_vault** HDRI from [Poly Haven](https://polyhaven.com/a/bank_vault), released under the [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) public-domain dedication.

The Aquanova project does not redistribute the individual Quaternius kit modules. Obtain them from [Quaternius](https://quaternius.com/) or use the configured BabylonAssets library.

The skybox under `runtime-assets/skybox/` was generated with [Space 3D](https://tools.wwwtyro.net/space-3d/), whose source is released under the Unlicense.

`runtime-assets/` is intentionally untracked. It also contains supplied weapon files and `sounds/spark.mp3`, for which no separate redistribution license has been documented. The local migration populates this directory, but those files must not be published in a public repository without confirming their licenses.
